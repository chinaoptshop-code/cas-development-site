# tools/img — конвеєр зображень

`tools/` не деплоїться. Скрипт працює лише з файлами в `img/` і `img/p/`; HTML тільки читає (щоб знайти зображення першого екрана).

## Що робить `build.py`

1. **Перекодовує WebP на місці** (той самий розмір у пікселях і назва), якщо:
   - менший варіант (напр. `-r1200`) важчий за більший (`-1400`) — «inversion»;
   - більше 0,22 байта на піксель — «over-quality» (лише якщо економія ≥ 12% при SSIM ≥ 0,97);
   - зображення першого екрана (hero) важче за 120 КБ (якщо якістю не влазить — легке попереднє розмиття 0,4–1,0 px, обирається варіант з найкращим SSIM).
2. **Пише `.avif` поруч із кожним `.webp`** (та сама базова назва). Якість підбирається для кожного файлу бінарним пошуком: ціль — AVIF ≈ 60% від WebP, але SSIM (сірий, половина роздільності, ≤768 px) щодо WebP ≥ 0,97, якість AVIF не нижче 40. Hero-AVIF ≤ 120 КБ.
3. **`img/lqip.json`** — `"img/p/<назва без розширення>"` → крихітний розмитий WebP як data-URI (≤ 300 байт).
4. **`tools/img/report.md`** — підсумки, перекодовані файли, hero, пропущені.

Пропускає: `img/og/`, `img/og-cas.jpg` (Open Graph — соцмережам потрібен JPEG), SVG/ICO.

## Як перезапустити

```bash
python3.12 -m venv /tmp/imgvenv && /tmp/imgvenv/bin/pip install 'pillow>=11.2' numpy
cd <корінь репо>
/tmp/imgvenv/bin/python tools/img/build.py            # лише нові/змінені (AVIF старший за WebP — пропускається)
/tmp/imgvenv/bin/python tools/img/build.py --force    # перекодувати всі AVIF
/tmp/imgvenv/bin/python tools/img/build.py --no-webp  # не чіпати WebP, лише AVIF + LQIP
```

Опції: `--jobs N` (паралельні процеси, за замовчуванням ядра − 2). Повний прогін ~1640 файлів на Mac mini M4 — кілька хвилин.
Повторний запуск безпечний: уже перекодовані WebP більше не потрапляють під критерії.

Нові фото: поклади `.webp` в `img/` або `img/p/` і запусти скрипт — зʼявляться `.avif` і запис у `lqip.json`.
Параметри (поріг SSIM, ціль AVIF, ліміт hero) — константи на початку `build.py`.
