# Monobank з Claude Code — `tools/monobank/`

`mono.sh` дає помічнику **лише читання** рахунків Монобанку через офіційний особистий API
(<https://api.monobank.ua/docs/>):

- баланси;
- виписки;
- підсумки надходжень і витрат;
- курси валют.

Платежі через цей API зробити неможливо: банк такої функції не дає.

Залежностей немає, потрібен лише Python 3.9+.

```bash
tools/monobank/mono.sh rates                       # курси USD/EUR/PLN (працює без токена)
tools/monobank/mono.sh me                          # усі рахунки, картки, банки з балансами
tools/monobank/mono.sh balance                     # коротко: баланси
tools/monobank/mono.sh statement --days 7          # операції за тиждень (рахунок за замовчуванням)
tools/monobank/mono.sh statement -a fop --from 2026-10-01 --to 2026-10-18
tools/monobank/mono.sh statement -a fop --days 30 --income          # лише надходження
tools/monobank/mono.sh statement --days 30 --search "Епіцентр"      # пошук в описі/коментарі/контрагенті
tools/monobank/mono.sh summary -a fop --days 30    # надходження/витрати, категорії, топ контрагентів
tools/monobank/mono.sh --json <команда> ...        # машиночитаний вивід
```

**`--account` / `-a`** вибирає рахунок. Можливі значення:

| Значення | Що вибирає |
|---|---|
| `0` (за замовчуванням) | основна картка |
| `fop` | рахунок ФОП |
| `black`, `white` | тип картки |
| `usd`, `eur` | валютний рахунок |
| `1111` | рахунок за кінцем IBAN або номера картки |
| id | рахунок за id з `me` |
| назва | банка |

**Ліміти банку:**
- запити до `/personal/*` — не частіше 1 разу на 60 с;
- виписка — до 31 доби й до 500 операцій за запит.

Скрипт сам чекає хвилину між запитами (і між запусками). Довгі періоди він ділить на частини, тож `summary --days 90` триває кілька хвилин. Це нормально.

## Налаштування (один раз)

1. Відкрийте <https://api.monobank.ua/> і відскануйте QR-код у застосунку Monobank. На сторінці з'явиться **токен** — довгий рядок.
   - Токен дає доступ лише до читання.
   - Відкликати його можна там же, кнопкою «Відкликати токен».
   - Якщо у вас є ФОП у Монобанку, його рахунки теж видно з особистим токеном.
2. Додайте змінну середовища **`MONOBANK_TOKEN`**:
   - **хмарна сесія Claude** — у налаштуваннях середовища (меню середовища → Edit → Environment variables);
   - **Mac mini** — у `~/.zshrc` (`export MONOBANK_TOKEN=...`) або в env launchd-агента бота.
3. Мережа: у хмарному середовищі має бути дозволений домен `api.monobank.ua`. Сьогодні він уже відповідає, тож нічого додавати не треба.
4. Перевірка: `tools/monobank/mono.sh balance`.

## Правила

- Токен ніколи не друкувати, не комітити й не записувати в пам'ять. Він живе тільки у змінній середовища.
- Цифри з рахунків — особисті дані. Вони не потрапляють у цей (публічний) репозиторій. Їх можна показувати тільки Михайлу (відповідь, тижневий огляд) і записувати лише в пам'ять на Drive.
- Помилки:
  - «Банк відхилив токен» — створіть новий токен на <https://api.monobank.ua/>;
  - «Немає зв'язку з api.monobank.ua» — перевірте мережевий дозвіл.
- Стан (час останнього запиту) лежить у `~/.mono-claude/`, поза репозиторієм. Інший шлях можна задати змінною `MONO_STATE_DIR`.
- Часовий пояс: `MONO_TZ`, за замовчуванням `ASSISTANT_TZ`, далі Europe/Kyiv.
