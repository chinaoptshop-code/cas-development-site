# Сценарій: читання і розвиток

Документ `04 Читання` містить: поточна книга (назва, сторінка/розділ, мета читання),
тези по розділах, черга книг, картки для повторення, «Відкладене» (статті, пости).

## Щоденно (у ранковому брифінгу)
- Один рядок: що читати сьогодні (розділ, скільки хвилин) з огляду на план.
- Якщо 3 дні немає відміток про читання: запропонувати менший крок (10 сторінок) або іншу книгу.

## Коли Михайло надсилає тези, фото сторінки, голосове про прочитане
- Записати тези в `04 Читання` під розділом книги.
- Створити 1–3 картки для повторення: «питання → відповідь», з датами повторення через 2, 7 і 30 днів.
- У вечірньому підсумку поставити одну картку, якій настав час.

## Після завершення книги
- Зібрати всі тези в конспект (Markdown → PDF), 1 сторінка «що застосувати в житті/компанії» з 3 конкретними діями → у `02 Задачі`.
- Запропонувати наступну книгу з черги з огляду на ціль кварталу.

## Відкладене (статті, пости, відео)
- Раз на тиждень (у тижневому огляді) нагадати про 3 найстаріші або запропонувати видалити.
