# Сценарій: записи зустрічей (Plaud, диктофон, голосові)

Вхід: запис у Plaud (через Plaud MCP), аудіофайл або транскрипт від Plaud (пересланий у наш чат
або покладений у Drive-папку «Асистент Михайла/Вхідні»), або довге голосове від Михайла.

## Plaud MCP (основний шлях)
Якщо в сесії є інструменти Plaud (конектор `mcp.plaud.ai`, назви на кшталт list/search recordings,
get transcript, get summary): коли Михайло пише «зроби тези по останній зустрічі», «що було на
зустрічі з …», «конспект запису від вівторка» — знайди запис через Plaud MCP за датою чи назвою,
візьми транскрипт (і готове резюме Plaud, якщо є) і далі за кроками 2–6. Аудіо завантажувати не
треба, транскрипт уже є. Якщо інструментів Plaud у сесії немає — скажи Михайлу один раз, що
Plaud не підключено до цієї сесії (конектор у налаштуваннях claude.ai або `claude mcp add` на
Mac mini), і попроси переслати запис файлом.

## Кроки
1. Отримати текст:
   - через Plaud MCP → транскрипт і резюме;
   - транскрипт (txt/md/pdf) → прочитати;
   - аудіо (mp3/m4a/wav/ogg) → `tools/telegram/tg.sh transcribe <чат> <id>` (якщо файл прийшов у Telegram) або локально: `~/.tg-claude/venv/bin/python -c` з faster-whisper (встановлюється `tools/telegram/tg.sh setup --whisper`). Довгі записи (понад 20 хв) різати ffmpeg на шматки по 10 хв.
2. Скласти конспект (Markdown):
```
# Зустріч: <з ким / тема>  — <дата>
**Учасники:** …  **Тривалість:** …
## Головне (3–5 тез)
## Рішення
## Дії
| Дія | Хто | Коли |
## Відкриті питання
## Ризики / на що звернути увагу
## Цитати, які важливо не загубити
```
3. Зберегти в Drive: `Зустрічі/YYYY-MM-DD <тема>`.
4. Дії, де «Хто» = Михайло → у `02 Задачі`; домовленості з людьми → у `06 Люди`; дати → запропонувати події в календар (створити, якщо дата й час однозначні).
5. Зробити PDF (`pdf.md`) і надіслати файлом + 5 рядків головного в Telegram.
6. Якщо Михайло просив «тези для клієнта/партнера»: зробити другу версію без внутрішніх коментарів і ризиків, показати чернетку, відправити адресату тільки після «так».
