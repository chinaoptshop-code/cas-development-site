# Сценарій: вечірній підсумок (щодня)

Мета: закрити день чесно й підготувати завтра. Якщо Михайло не відповідає — не чіплятися.

## Кроки
1. Обробити вхідні (`inbox.md`), якщо є нові.
2. Прочитати ранковий план із Журналу, `02 Задачі`, `03 Звички і спорт`, `04 Читання`.
2a. **Пройти по всіх проєктах** — прочитати кожен файл памʼяті з номером 08 і вище
   (`08 Микуличин`, `13 Офісна ніша`, `14 Ресторан Вишневе` і будь-які нові).
   З кожного взяти те, що **блокує або чекає рішення Михайла**, не переказувати зміст.
2б. **Нагадування на завтра:** у `02 Задачі.md` знайти розділ «## Сьогодні / <завтрашній день дд.мм>» (і рядки з 🔔 на завтра) —
   усі невиконані пункти перелічити в повідомленні окремим блоком «🔔 Завтра нагадати: …». Це те, що Михайло просив
   «нагадай завтра» — пропускати не можна, навіть якщо пункт дрібний (напр. «полити квіти» — теж).
3. Подивитися календар на завтра.
4. Надіслати повідомлення:
```
🌙 Підсумок дня
Планував: 1) … 2) … 3) …
Відміть, що зроблено (напиши номери або «все»/«нічого»), і 1 речення: що сьогодні було найкращим?
🏋️ Тренування було? 📖 Скільки сторінок?
Завтра: 09:30 …, 14:00 … Перша задача ранку: …
🔔 Завтра нагадати: … · … (усі пункти розділу завтрашнього дня)

📁 Проєкти:
• <назва> — <що блокує або чекає рішення>
• …
```
Рядок проєкту — лише там, де є що сказати. Проєкт без руху й без блокера
не згадуємо: список має лишатись коротким, інакше його перестануть читати.
5. Відповідь Михайла прийде в наступному проході `inbox.md`: тоді оновити задачі (зроблені → у «Зроблено» з датою), звички, читання і дописати `### Вечір` у Журнал.

## Правила
- Не читати мораль. Якщо нічого не зроблено: «Буває. Завтра перша задача: …».
- Раз на три дні ставити одне запитання для розвитку (що відкладаєш і чому; що робив би, якби не боявся; де втрачаєш час).
- Без Markdown-зірочок і решіток: Telegram їх не малює (скрипт сам зробить <b> з **назв**, але краще просто текст).
