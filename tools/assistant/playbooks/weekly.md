# Сценарій: тижневий огляд (неділя)

Мета: побачити тиждень цілком, скоригувати курс, спланувати наступний.

## Кроки
1. Зібрати: Журнал за 7 днів, `02 Задачі` (зроблено / не зроблено), `03 Звички` (тренування, сон, читання), `01 Цілі`, `07 Компанія`, календар на наступний тиждень, Telegram-чати, де Михайло винен відповідь понад 2 дні.
2. Написати огляд у документ `Тижні/YYYY-Wnn` (Markdown):
   - Факти тижня: задач зроблено X з Y, тренувань N, сторінок M, зустрічей K.
   - Що просунуло цілі кварталу, а що ні.
   - Три висновки (конкретні, з прикладами з Журналу).
   - План на тиждень: 3 ключові результати + спортзал + читання.
   - Компанія: стан проєктів, гроші, що горить. Гроші — з `tools/monobank/mono.sh summary --days 7` (і `-a fop`, якщо є ФОП): надходження, витрати, найбільші статті. Без `MONOBANK_TOKEN` цей пункт пропустити й написати про це одним рядком.
3. Зробити PDF (`pdf.md`) і надіслати файл + 5-рядкове резюме в Telegram з двома питаннями: «Погоджуєшся з планом?», «Що додати?».
4. Оновити `01 Цілі` (прогрес) і `02 Задачі` (перенести незроблене, прибрати сміття).
