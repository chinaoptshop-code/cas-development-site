# Сценарій: вхідні (кожну годину вдень)

Мета: Михайло пише мені будь-що в наш чат (голосом чи текстом), а я це перетворюю на дію.

## Кроки
1. `tools/assistant/bin/inbox.sh` → JSON із новими повідомленнями. Якщо `new` порожній — завершити мовчки, нічого не надсилати.
2. Для кожного повідомлення:
   - голосове (`media` починається з `voice`) → `tools/telegram/tg.sh transcribe <чат> <id>`;
   - аудіо/файл (`audio`, `file`) → `tools/telegram/tg.sh download <чат> <id>` і далі за типом: аудіозапис Plaud → сценарій `meeting-notes.md`; PDF/документ → прочитати, зробити що просить; фото → подивитися інструментом Read;
   - пересланий пост або посилання без коментаря → зберегти в `04 Читання` (розділ «Відкладене») одним рядком із тезою;
   - текст → визначити намір (нижче).
3. Виконати, записати в пам'ять, відповісти одним повідомленням на всі нові (з `--reply-to` на останнє).

## Наміри (приклади → дія)
| Михайло пише | Я роблю |
|---|---|
| «Нагадай у четвер о 10 подзвонити Олегу» | подія в Google Calendar з нагадуванням + рядок у `02 Задачі` |
| «Завтра зустріч з клієнтом о 15 на об'єкті» | подія в календарі (60 хв, якщо не сказано інше), запитую адресу тільки якщо її немає в пам'яті |
| «Додай задачу: …», або просто дієслово в наказовій формі | рядок у `02 Задачі` (розділ за терміном) |
| «Зробив тренування», «прочитав 30 сторінок» | відмітка в `03 Звички і спорт` / `04 Читання`, коротке «зараховано» |
| «Що в мене завтра?» | календар на завтра + задачі з дедлайном |
| «Тези по цьому (файл/голосове)» | конспект → PDF (`pdf.md`) → надіслати файлом |
| «Запиши рішення: …» | запис у `05 Рішення` з датою і причиною |
| «Напиши Олегу, що …» | чернетку показати, відправити ТІЛЬКИ після «так» |
| «Знайди в тг, що казав Андрій про кошторис» | `tg.sh search` → короткий витяг з датами |
| «Що там у пошті?» | Gmail: непрочитане за добу, 5 найважливіших одним рядком кожне |
| Питання про життя, бізнес, книгу | відповідь по суті, спираючись на пам'ять; якщо треба, пропоную записати як рішення або задачу |
| Будь-що незрозуміле | роблю найімовірніше і кажу, що зробив; не ставлю уточнень без потреби |

## Голосові від Михайла
Голосове — це нормальний спосіб команди. Після розшифровки дію як із текстом. У відповіді
перший рядок: що я зрозумів («Зрозумів: додати задачу …»).
