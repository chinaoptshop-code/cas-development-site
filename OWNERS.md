# Хто де працює

Два агенти в одному репозиторії неминуче розривають файли. 19.10.2026
довелось тричі перезливати гілку в `cas-development-site`, бо друга сесія
пушила швидше. Тому межі закріплено тут.

| Репозиторій | Хто веде | Що всередині |
|---|---|---|
| `~/jarvis` | **сесія «Mac Mini · JARVIS»** | боти, агенти, кошториси, договори, креативи, архів Telegram, інфраструктура |
| `~/cas-development-site` | **друга сесія** | особистий помічник, сценарії, інструменти Telegram і Monobank, сайт cas-develop.com |
| `~/cas-web` | **вільний** | сайти: комплектація з Китаю, лендинги |
| `~/supplier-agent` | нічий, рідко чіпають | бот постачальників. ⚠️ Python 3.9 — сучасний синтаксис його валить |

## Правила
1. **Не редагуй файли в чужому репозиторії.** Треба зміна — скажи Михайлу.
2. Перед `push` завжди `git fetch` і `git rebase origin/main`.
3. Кожна зміна — окремий коміт українською, із поясненням чому.
4. Якщо побачив чужі свіжі коміти — зупинись і перевір, чи не робите те саме.
